Швидке та надійне резервне копіювання сайтів від UAServer. Безкоштовна версія для ручного створення копій.

== Description ==

UA Backup - це легкий та швидкий інструмент для створення резервних копій вашого сайту на WordPress. Плагін розроблено командою найшвидшого локального сервера UAServer.

= Особливості безкоштовної версії =
* Створення повного бекапу сайту (файли + база даних) в один клік.
* Оптимізована робота з базами даних без навантаження на хостинг.

= Переваги версії Pro =
Для повної автоматизації доступний перехід на довічну PRO ліцензію за 599 грн (PayPal).
* Автоматичне резервне копіювання за розкладом (Cron).
* Автоматичні оновлення плагіна безпосередньо через вашу адмінку.
* Придбати ліцензію: https://uaserver.pp.ua

== Installation ==

1. Завантажте папку з плагіном у директорію `/wp-content/plugins/`.
2. Активуйте плагін через меню 'Плагіни' в адмінці WordPress.
3. Перейдіть до меню 'UAServer plugins' -> 'UA Backup' для налаштування.
