# UA Backup 2.1.0

Плагін WordPress для створення повного ZIP-бекапа (файли + база даних) і перенесення сайту на інший хостинг.

## Що реалізовано

- Створення повного ZIP-архіву з перевіркою цілісності.
- Індикатор фактичного прогресу створення бекапа.
- Захист від паралельного запуску копіювання.
- Одноразовий ключ для запуску інсталятора.
- Поетапне відновлення в порожню базу даних.
- Перевірка доступу до БД, налаштування префікса таблиць.
- Вибір адміністратора з копії або створення нового.
- Оновлення адрес сайту з обробкою PHP serialized values.
- Оновлення параметрів бази даних у wp-config.php.
- Автоматичне очищення службових файлів після успішного перенесення.

## Вимоги

- WordPress 6.0+
- PHP 7.4+
- PHP ZipArchive
- mysqli на хостингу, куди переноситься сайт

## Встановлення

Завантажте ZIP плагіна через **Плагіни → Додати новий → Завантажити плагін**, активуйте та відкрийте **Інструменти → UA Backup**.

## Перенесення

1. Створіть бекап і скопіюйте одноразовий ключ, який покаже плагін.
2. Завантажте ZIP бекапа в кореневу папку нового домену та розпакуйте.
3. Відкрийте `/installer.php`, введіть ключ і дані порожньої бази.
4. Перевірте підключення, відновіть базу, виберіть адміністратора та завершіть процес.
5. Перевірте сайт і вхід в адмінку, перш ніж видаляти ZIP бекапа.

**Увага:** не запускайте відновлення в базу з наявними таблицями. Перед перенесенням збережіть резервну копію файлів цільового хостингу.
